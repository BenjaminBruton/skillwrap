## Printing Instructions

To create PDF versions of these templates:

1. **Option 1 - Using Markdown to PDF converter:**
   - Use a tool like Pandoc: `pandoc WAIVER_CONFIRMATIONS.md -o WAIVER_CONFIRMATIONS.pdf`
   - Or use an online converter like [Markdown to PDF](https://www.markdowntopdf.com/)

2. **Option 2 - Using a Markdown viewer:**
   - Open this file in VS Code
   - Right-click and select "Markdown: Open Preview"
   - Print from the preview (Cmd+P on Mac, Ctrl+P on Windows)
   - Save as PDF

3. **Option 3 - Copy to Word/Google Docs:**
   - Copy the content for each waiver
   - Paste into Word or Google Docs
   - Format as needed
   - Save as PDF

## Usage Notes

- Replace all bracketed placeholders [like this] with actual information
- For physical waivers, have the parent/guardian fill in their information
- Keep these printed confirmations on file with the corresponding waiver documents
- Each waiver should include the date signed and parent signature
